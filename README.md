# Number Guessing Game

## Project Overview

This project is a simple number guessing game created using Python. The game prompts the player to guess a randomly generated number within a specified range. The player receives feedback on whether their guess is too high, too low, or correct, making it an engaging and fun way to practice basic programming concepts and control flow in Python.

## Features

- **Random Number Generation**: The game generates a random number that the player must guess.
- **User Input**: Players can input their guesses and receive immediate feedback.
- **Feedback Mechanism**: After each guess, the game informs the player if their guess is too high, too low, or correct.
- **Score Tracking**: Players can keep track of the number of attempts it takes to guess the number correctly.
- **Replay Option**: After finishing a game, players can choose to play again.

## Technologies Used

- **Python**: The primary programming language used for this project.
